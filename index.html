What is CSS?

CSS (Cascading Style Sheets) controls how your HTML looks. If HTML is the structure of a house, CSS is the paint, lighting, and layout.

Purpose

Make pages beautiful

Change colors, fonts, spacing, and alignment to create a clean UI.

Layout

Arrange content

Use modern layout tools like Flexbox and Grid to build responsive pages.

Experience

Add delight

Hover effects, transitions, and subtle animations improve usability.

Quiz: What does CSS mainly control?
Explanation: HTML provides structure and content, while CSS controls styling like colors, spacing, and layout.

CSS Syntax

A CSS rule targets something (a selector) and applies styles (properties) with specific values.

Example rule 
h1 {
	color: #22d3ee;
	font-size: 40px;
}

Selector

Who are we styling? Example: h1, .card, #app

Property

What are we changing? Example: color, margin, display

Value

What do we set it to? Example: 16px, center, #111827

Quiz: In .btn { color: red; }, what is color?
Explanation: .btn is the selector, color is the property, and red is the value.

Types of CSS

There are three common ways to add CSS. All work, but they are used for different scenarios.

Inline

Inside an element

Quick for tiny edits. Hard to maintain for real projects.

<h1 style="color:cyan">...</h1>

Internal

Inside the HTML file

Useful for small pages and demos. Still can grow messy.

<style> h1{...} </style>

External

Separate .css file

Best for maintainability. Reusable across multiple pages.

<link rel="stylesheet" href="styles.css">

Quiz: Which type of CSS is generally best for real projects?
Explanation: External CSS keeps styles organized and reusable, which is easier to maintain as projects grow.

Selectors

Selectors decide which HTML elements receive your styles.

Element

p or button

Targets all elements of that type.

p { color: #a6b0c0; }

Class

.card

Reusable style. Many elements can share one class.

.card { padding: 16px; }

ID

#header

Unique element. Use sparingly.

#header { position: sticky; }

Quiz: Which selector targets an element with id="app"?
Explanation: IDs use #, classes use ., and elements are written by tag name.

Properties & Values

Think of a property as a setting and the value as what you set it to.

Color

color: #22d3ee; changes text color.

background: #111827; changes background.

Spacing

margin adds space outside an element.

padding adds space inside an element.

Example 
.card {
	margin: 16px;      /* outside */
	padding: 16px;     /* inside */
	color: #e5e7eb;
	background: rgba(255,255,255,.06);
}
Quiz: Which property adds space inside a box?
Explanation: Padding is the inner spacing between the content and the border.
